# Attribution & Provenance

This project relies on algorithms published in the following works:

1. **ModelXRay**: Gilkarov & Dubin (2024). *Model X-Ray: Detection of Hidden Malware in AI Model Weights using Few Shot Learning*. arXiv:2409.19310.
   - Implemented: GF representation, B1-B7 baselines, X-LSB-Fill.
   - Note: Clean room reimplementation; no code from original repo used due to CC BY-NC-ND license restrictions.
2. **Implicit Features**: Cao et al. (2026). *Steganalysis of Neural Networks Using Implicit Features*.
   - Implemented: model-06-long detector.
3. **TransTroj**: Wang et al. (2025). *TransTroj: Transferable Backdoor Attacks to Pre-Trained Models*.
   - Implemented: Benchmark evaluation framework.
4. **Dixon Q-Test**: Fields et al. *Trojan Signatures in DNN Weights*.
